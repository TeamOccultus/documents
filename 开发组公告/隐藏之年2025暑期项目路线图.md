# 隐藏之年 2025 暑期项目路线图

由于我们的学业问题，隐藏之年自本年三月以来没有得到应有的维护，但幸而在暑期我们有比较充裕的时间进行开发。

为了使玩家对本模组的未来更新有更明确的认知，在此我们将整个暑期以及暑期以后的任务归纳为该路线图，供玩家参考与反馈。

## 短期目标

目前，我们主要聚焦在隐藏之年原有的游戏内容上，并预计对其进行一次彻底的重构，优化或移除玩家负面反馈较多的游戏内容，例如：

- 仿制材料；
- 某些不平衡的交易表；
- 过多的前中期材料；
- 某些由于历史原因早已失去功能的游戏内容，比如那个什么精华 *（是的，连我也忘掉它的名字了） * ；
- 其他容易被误认为漏洞的游戏内容；
- 以及其他……

在这之前，我们将会改善开发组的工作流程，隐藏之年先前的工作流程存在诸多大量重复的、相同的、可被机器替代的工作，例如：

- 人工进行附加包文件的打包；
- 人工对工程文件进行部署。

这些工作大大减缓了我们的工作效率，因此我们将会编写专门的脚本来统一完成这些工作，并在时机成熟时将其以软件包的形式发布到 NPM 上，为其他开发者提供便利。

除此之外，鉴于基岩版目前接口已经较为成熟，我们将会开放更多 API 给附属模组。

### 改善工作流程

上文已经提到，不完善的工作流程严重减慢了我们的工作效率，对此我们将会编写一个专门的软件包`@starock/cli`解决这一问题。

此外，我们将会争取让开发组的每一位成员在条件允许的情况下，都参与到隐藏之年的开发中，以加快我们的开发速度。

尽管对于工作流程的改善带来的影响表面上对玩家的影响并不强烈，但事实上却大大提高了我们的工作效率和工作质量。

因此，无论是对于玩家还是对于开发者来说，这部分工作都是重要的。

### 原有内容的重构

隐藏之年自 2023 年 5 月发布第一个正式版以来，已经有了两年多的历史，在这段时间内基岩版的接口发生了翻天覆地的变化，尽管我们一直以最大的努力来第一时间适配新版本，但仍不可避免地存在一些难以放下的历史包袱。

除此之外，由于一些奇妙的原因，开发组目前丢失了一部分远古游戏内容的策划案，导致我们也摸不清一些游戏内容的用处了（

由此可见，对隐藏之年进行一次完全地、彻底地重构是相当有必要的。

在重构中，内容会发生变化的游戏内容有：

- 矿物系统；
- 材料系统；
- 工具和武器；
- 交易系统；
- 任务系统；
- 以及几乎所有其他游戏内容！

重构后的版本将不会和之前相兼容，为了与之前的版本区分，重构后的隐藏之年的标题统一改为 **《隐藏之年²：天边的迦万涅尔》（Hidden Years²: Governor at the Skyline）**。

### 开放更多第三方接口

在之前，囿于基岩版有限的接口，我们只能通过开放特定物品或方块标签的形式，来实现开放第三方接口。

但随着带参数的自定义组件以及自定义命令的添加，先前的标签系统显得太过简陋，可配置性也相当的低，正所谓「逸一时、误一世」，这势必会对隐藏之年的社区造成不利影响。

为此，我们将会在重构游戏内容的过程中，开放更多自定义组件以供使用，甚至会开放一些自定义命令，同时完善文档，方便社区的开发。

### 官网

官网作为隐藏之年的信息门户，承担着相当重要的任务，鉴于我们人手短缺，所以新官网仍选用 Vuepress 框架，在此基础上添加以下内容：

- 重构后所有游戏内容的介绍；
- 所有版本的更新日志或者说明；
- 技术性信息；
- 其他信息（如著作权信息、开发组成员信息等）

## 中期目标

在短期目标完成后，我们将会添加一些关于冒险模组的相关元素，包括但不限于：

- 职业系统；
- 重新设计的任务和成就系统；
- 引导系统。

除此之外，我们将会补全缺失的音效与音乐，并在合适的时候对实体的相关资源做出进一步优化。

我们也将完善世界观，并让世界观与游戏内容充分结合，让玩家看得见、摸得着。

### 客户端资源优化

目前，隐藏之年仍缺少一些音效和音乐，如「创世者」的愤怒缺少所有的 BOSS 音效，一些音乐也需要重写，我们将会尽快补全。

我们将会制作一个 PBR 纹理包，来适配基岩版新添加的 Vibrant Visuals。

除此之外，我们预计向游戏中加入一些音乐唱片，同时将音乐实装在附加包本体中，不再单独分发。

在合适的时候，我们将会对实体的相关资源做出进一步优化。

### 隐藏乐事

由于重构后的隐藏之年不会与旧版本兼容，因此我们在隐藏之年本体完成重构之后也迎来重构。

如有可能，我们也会加入更多的新食品。

### 更多冒险元素的添加

目前，隐藏之年的冒险元素还比较少，因此我们计划添加以下冒险元素：

- 更多的遗迹与地牢；
- 职业系统，包含：
	- 职业等级；
	- 属性点；
	- 职业技能；
	- 职业专精；
- 饰品系统；
- 与法器相关的魔法系统；
- 引导系统；
- 成就系统；
- 以及更多……

在未来我们将会披露关于这些内容的详细信息。
### 世界观的完善

过去，世界观主要是以散落在世界各地的阅读物形式出现的，但这种方法太过于隐晦，导致几乎没有玩家注意到隐藏之年的世界观。

*比如，连开发组的主美术都不知道《隐藏之年²：天边的迦万涅尔》中的迦万涅尔是谁。*

在新版本中，我们将会在任务中插入更多世界观相关内容，同时大部分阅读物将可以直接通过任务获取。

我们还会添加一个新道具，其将根据玩家的游戏进度，系统地梳理世界观与剧情，方便玩家理解。

至于为什么要把该任务列入中期目标呢？因为世界观的撰写和整理需要一定时间（

### 完善外文翻译

当前，隐藏之年先前的版本已经有了较为完整的英文翻译，但随着内容的重构，许多游戏文本也发生了变化，因此对外文翻译进行必要的修正，以及添加新文本的翻译是十分必要的。

如果时间允许，我们将会将隐藏之年翻译为更多不同的语言，并将其翻译文件放在 Crowdin 上，允许社区贡献翻译。

### 幽匿主题更新

顾名思义，一切完成后，我们将会开始策划幽匿主题的相关更新。

对此我们不能透露太多，毕竟我们也没有敲定最终该做些什么（

## 长期目标

这些长期目标可能暑期无法完成，目前我们的工作重心也没有放在这些目标上，但我们仍将不断坚持，争取早日完成。

### 添加简单机械

我们希望可以添加一整套基于燃金的机械系统，来方便玩家的游玩体验。

因此我们将会从简单的机械着手，逐步积累经验，在遥远的未来考虑添加更多、更复杂的机械。

### 其他版本移植

对于 Java 版而言，目前我们缺少这方面的经验，因而会很久都没有进展。

对于网易版而言，由于网易版使用的 Mod SDK 与基岩版的 Script API 完全不同，而我们人手不足，因此暂时不作打算。

短期内，由于我们长期以来侧重于基岩版，我们的开发重心依旧会放在基岩版的开发上，但我们仍旧希望在 Java 版的开发上作出进展，并得到一些可见的结果。 

### 发布每周动态

倘若开发组有活动，我们会每周不定时发布该周的更新内容到苦力怕论坛、哔哩哔哩上，以供玩家了解。

## 结语

隐藏之年来自于社区、服务于社区，望各位玩家积极监督、不吝建言，同我们一道将隐藏之年打造为基岩版一流的大型冒险模组！
